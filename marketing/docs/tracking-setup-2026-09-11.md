### 6.2 تتبّع النقر على زر واتساب كـ Lead (قبل `</body>`)

```html
<script>
  document.addEventListener('click', function (e) {
    var link = e.target.closest('a[href*="wa.me"], a[href*="api.whatsapp.com"], a[href^="whatsapp:"]');
    if (!link) return;
    if (typeof fbq === 'function') fbq('track', 'Lead');
    if (typeof gtag === 'function') gtag('event', 'generate_lead');
  });
</script>
```

- يلتقط كل روابط واتساب في الصفحة (الزر العلوي والعائم وغيرهما) دون تعديل كل زر على حدة.
- يُفضَّل فتح روابط واتساب في تبويب جديد (`target="_blank" rel="noopener"`) حتى لا تُغلق الصفحة قبل إرسال الحدث.
- يجب أن يبقى اسم الحدث في GA4 `generate_lead` حرفيًّا ليُحتسب كـ Key event.
- سيسجّل GA4 أيضًا حدث `click` تلقائيًا للروابط الخارجية (Enhanced measurement)؛ وهو منفصل ولا يتعارض.
